## 1. 시스템 개요 및 아키텍처 (Architecture)

* **초대 합류:** 원장의 초대 링크를 통해서만 강사 가입 가능.

### 1.2 과금 및 인원 정책

* **Free Plan:** 학원당 3명 제한.
* **확장:** 인원 초과 시 "고객센터 문의" 모달 노출 -> 슈퍼 어드민(개발자)이 DB/API를 통해 수동으로 Limit 상향 조정.

```sql
-- 1. 학원 (Tenants)

-- 3. 학생 (Students) - [UPDATED: 학번/학년 규칙]
CREATE TABLE `students` (

    `student_number` VARCHAR(20) NOT NULL COMMENT '시스템 자동 채번 (학원별 유니크)',
    
    `name` VARCHAR(50) NOT NULL,
    `school` VARCHAR(50) NULL,
    
    -- [v5.1] 학년 통합 코드 (Division 내포)
    -- E1~E6(초), M1~M3(중), H1~H3(고), N(기타)

    FOREIGN KEY (`academy_id`) REFERENCES `academies` (`academy_id`),
    -- 학원 내에서 학번은 중복될 수 없음
    UNIQUE KEY `uk_academy_student_num` (`academy_id`, `student_number`)

-- 4. 강의 및 스케줄 (Lectures)
CREATE TABLE `lectures` (

CREATE TABLE `schedules` ( -- 정규 시간표
    `schedule_id` BIGINT AUTO_INCREMENT PRIMARY KEY,
    `lecture_id` BIGINT NOT NULL,
    `day_of_week` VARCHAR(3) NOT NULL,
    `start_time` TIME NOT NULL,
    `end_time` TIME NOT NULL

-- 5. 수업 기록 (Records) - [보강 관리]
CREATE TABLE `lecture_records` (
    `record_id` BIGINT AUTO_INCREMENT PRIMARY KEY,
    `academy_id` BIGINT NOT NULL,
    `lecture_id` BIGINT NOT NULL,
    `student_id` BIGINT NOT NULL,
    `date` DATE NOT NULL,
    
    `actual_start_time` TIME NULL, 
    `actual_end_time` TIME NULL,
    
    `attendance_status` ENUM('ATTENDED','LATE','ABSENT','REQ_MAKEUP','MAKEUP') NOT NULL,
    `linked_record_id` BIGINT NULL,
    
    `daily_log` TEXT NULL,
    `material_info` JSON NULL,
    
    FOREIGN KEY (`linked_record_id`) REFERENCES `lecture_records` (`record_id`)

-- 6. 정산 (Settlements) - [세금 관리]
CREATE TABLE `settlements` (
    `settlement_id` BIGINT AUTO_INCREMENT PRIMARY KEY,

-- 7. 교재 (Materials - Hybrid)

    `material_id` BIGINT AUTO_INCREMENT PRIMARY KEY,
    `academy_id` BIGINT NULL,
    `isbn` VARCHAR(20) NULL,

    INDEX `idx_material` (`academy_id`, `title`)
```

## 3. 핵심 비즈니스 로직 (Logic Specification)

### 3.1 학년 및 부서 통합 (Grade Hierarchy)

* **정책:** DB에는 `grade` 코드만 저장하고, 비즈니스 로직에서 `Division`을 도출한다.
* **코드 매핑:**
* **초등(Elementary):** `E1`, `E2`, `E3`, `E4`, `E5`, `E6`
* **중등(Middle):** `M1`, `M2`, `M3`
* **고등(High):** `H1`, `H2`, `H3`
* **기타(None):** `N` (성인, 재수생 등)


* **조회 로직:** "초등부 전체 조회" 요청 시 `WHERE grade IN ('E1'...'E6')` 쿼리로 변환 처리.

### 3.2 학번 자동 생성 규칙 (Auto-Generation)

* **포맷:** `{YYYY}{SEQ}` (예: 20260001, 20260002 ...)
* **규칙:**
* **연도(YYYY):** 등록 시점의 연도 4자리.
* **일련번호(SEQ):** 4자리 (0001부터 시작).


* **격리 조건 (중요):** 일련번호는 **학원(`academy_id`)별로 별도로 카운팅**되어야 한다.
* A학원 2026년 1호 학생 -> `20260001`
* B학원 2026년 1호 학생 -> `20260001` (중복 허용, `academy_id`로 구분됨)



### 3.3 시간표 변경 정책 (Schedule Update Policy)

캘린더에서 반복 일정을 수정할 때의 파급 범위 정책.

* **Instance (이 일정만):** `schedules` 유지, 해당 날짜 `lecture_records` 생성/수정.
* **Series (앞으로 모두):** `schedules` 수정. 단, **과거의 `lecture_records`는 수정 금지**.

### 3.4 보강 관리 시스템 (Makeup Class)

* **결석 처리:** `REQ_MAKEUP` 상태 저장 (정산 0원).
* **보강 잡기:** 보강 수업(`MAKEUP`) 생성 시 원본 결석 레코드와 `Link`. (정산 1회 인정).

### 3.5 퇴원 및 정산 일할 계산

* **퇴원:** `status=DISCHARGED`, `discharge_date` 입력.
* **정산:** 수업일 > 퇴원일인 경우 정산 집계 제외.

### 3.6 정산 및 세금

* `세전 총액(Total)` =
* `공제액(Tax)` = `Total`  0.033
* `실지급액(Real)` = `Total` - `Tax`

## 4. API 명세서 (API Specification)

### 4.1 [Admin] 테넌트 및 인원 관리

* `POST /api/v1/academies`: 학원 생성.
* `PUT /api/v1/instructors/{id}/approve`: 강사 승인 (Max Member 체크).

### 4.2 [Student] 학생 관리 (Updated)

* `POST /api/v1/students`
* **Request:** `name`, `grade` (E1, M2...), `parent_phone`... (학번 제외)
* **Logic:** 서버 내부에서 `2026...` 학번 생성 후 저장.


* `DELETE /api/v1/students/{id}`
* **Logic:** `status=DISCHARGED` 업데이트 (논리 삭제).



### 4.3 [Schedule] 일정 및 보강

* `PUT /api/v1/schedules/{id}`: Body `{ "scope": "INSTANCE" | "SERIES" ... }`
* `POST /api/v1/records`: Body `{ "attendanceStatus": "MAKEUP", "linkedRecordId": ... }`

### 4.4 [Settlement] 정산

* `GET /api/v1/settlements/dashboard`: `total`, `tax`, `real` 반환.

## 5. 프론트엔드 가이드 (Frontend Guide)

### 5.1 학생 등록/수정 폼

* **학년 선택 UI:** 드롭다운으로 제공하되, "초등 1학년" 선택 시 `E1` 코드로 전송.
* **학번 UI:** 등록 시에는 입력 필드 없음(자동생성). 상세 조회 시에는 `Read-Only` 텍스트로 표시.

### 5.2 일정 수정 모달

* 반복 일정 클릭 시: `[이번 일정만 변경]` vs `[앞으로 모든 일정 변경]` 선택 팝업 필수.

### 5.3 보강 잡기 UX

* 일정 추가 팝업 -> [보강] 탭 -> "보강 미배정 학생(결석자)" 리스트 조회 및 선택.
