## 1. 개발 히스토리 (Development History)

### ✅ 1주차 (2026-01-14 ~ 01-16)
*   **작업 목표**: 멀티 테넌시 기반 재설계 및 기초 데이터 관리
*   **완료 사항**:
    *   **인증/가입**: `authStore` 리팩토링, 학원 생성/초대 가입 API 연동.
    *   **관리자 기능**: 강사 승인, 인원 제한 모달(`PlanLimitModal`).
    *   **수강생 관리**: 학년 드롭다운, 학번 자동 생성 표시, 퇴원 처리 UI 구현.

### ✅ 2주차 (2026-01-17 ~ 01-19)
*   **작업 목표**: 핵심 비즈니스 로직 (시간표 & 보강)
*   **완료 사항**:
    *   **시간표 변경 정책**: `ScheduleEditModal` 구현 (Instance vs Series 선택).
    *   **수업 기록(LMS)**: `LectureRecordModal` 구현 (출결/일지 저장, `REQ_MAKEUP` 상태 추가).
    *   **보강 잡기 UX**: `MakeupScheduleModal` 구현 (빈 시간 클릭 -> 보강 필요 학생 선택 -> 연결).
    *   **캘린더 고도화**: 통합 뷰(Grouped View) 및 상세 모달(`GroupDetailModal`) 구현.
    *   **강의 관리 고도화**: 시간표 동시 입력 및 목록 조회 개선.

### ✅ 3주차 (2026-01-20 ~ 01-22)
*   **작업 목표**: 정산 및 데이터 시각화, 교재 관리
*   **완료 사항**:
    *   **정산 관리**: 대시보드, 상세 내역 테이블, 엑셀 다운로드 기능 구현.
    *   **교재 관리**: 하이브리드 검색(공용/전용) 및 등록 기능 구현.
    *   **에러 핸들링**: 401 Unauthorized 발생 시 자동 로그아웃 인터셉터 추가.

### ✅ 4주차 (2026-01-23 ~ 01-25)
*   **작업 목표**: 안정화 및 배포 (Stabilization)
*   **완료 사항**:
    *   **수강생 강의 배정 (Enrollment)**: 수강 신청/취소 UI 및 API 연동 완료.
    *   **캘린더 최적화**: FullCalendar 날짜 범위(`start`, `end`) 기반 동적 데이터 로딩 구현.
    *   **통합 테스트 및 버그 픽스**:
        *   강사 승인, 강의/학생 목록 조회 시 ID 참조 및 권한 오류 수정.
        *   캘린더 반복 일정 누락 문제 해결 (`useGroupedEvents` 로직 개선).
    *   **기능 고도화**:
        *   예상 정산 금액(Forecast) 조회 및 대시보드 UI 개편 (확정/예상/총액).
        *   수강생 등록 시 전화번호 자동 포맷팅 적용.
