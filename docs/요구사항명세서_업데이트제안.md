# 요구사항 명세서 업데이트 제안 (v5.1 -> v5.2)

개발 과정에서 발견된 누락 사항과 구체화된 로직을 반영하기 위한 제안서입니다.

## 1. 캘린더 및 시간표 (Schedule)
*   **[추가] 통합 뷰 (Grouped View) 정책**:
    *   동일 시간대(또는 겹치는 시간대)의 수업은 하나의 블록으로 묶어서 표시한다.
    *   블록 내부에는 개별 수업의 시간과 제목을 리스트 형태로 표시한다.
    *   그룹 블록 드래그 시 포함된 모든 수업 일정이 동시에 변경된다.
*   **[수정] 동적 기간 조회**:
    *   캘린더 뷰(월/주/일) 변경 시 `start`, `end` 파라미터를 사용하여 해당 기간의 데이터만 조회한다.

## 2. 강의 및 수강생 관리 (Lecture & Student)
*   **[추가] 강의 생성 시 시간표 동시 등록**:
    *   강의 기본 정보(이름, 가격 등)와 정규 시간표(요일, 시간)를 한 번의 요청으로 생성한다.
*   **[추가] 수강생 강의 배정 (Enrollment)**:
    *   수강생 상세 페이지에서 '수강 중인 강의'를 조회하고 추가/취소할 수 있어야 한다.
    *   API: `GET /api/v1/students/{studentId}/lectures` (학생 기준 조회)

## 3. 정산 (Settlement)
*   **[구체화] 상세 내역 제공**:
    *   정산 대시보드에서 특정 강사를 선택하면, 해당 정산 금액이 산출된 근거(수업별 내역)를 제공해야 한다.
    *   API: `GET /api/v1/settlements/{id}/details`

## 4. 교재 (Material)
*   **[구체화] 하이브리드 검색**:
    *   교재 검색 시 '공용 DB(알라딘 등)'와 '학원 전용 DB'를 통합하여 결과를 반환한다.
    *   학원 전용 교재는 별도의 뱃지(Badge)로 구분한다.

## 5. 시스템 (System)
*   **[추가] 인증 만료 처리**:
    *   `401 Unauthorized` 응답 발생 시, 프론트엔드는 즉시 로그아웃 처리하고 로그인 페이지로 리다이렉트한다.
