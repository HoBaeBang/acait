## 2. 상세 개발 일정 (Roadmap)

### 📅 1주차: 멀티 테넌시 기반 재설계 (Foundation)

**목표:** 학원별 데이터 격리 구조를 프론트엔드에 적용하고, 새로운 가입 플로우를 완성합니다.

*   **Day 2: 학원 생성 및 초대 가입 API 연동 (Next)**
    *   백엔드 API(`POST /academies`, `POST /auth/signup`) 연동.
    *   학원 생성 성공 시 Owner 권한으로 자동 로그인 처리.
    *   초대 가입 신청 시 승인 대기 화면(`PendingPage`) 연결.
*   **Day 3: 강사 승인 및 인원 제한**
    *   관리자 페이지: 강사 승인 시 `403 PLAN_LIMIT` 에러 핸들링 (고객센터 문의 모달).
*   **Day 4: 수강생 관리 고도화 (퇴원/학번/학년)**
    *   **[v5.1] 학년 선택 UI**: `E1`~`H3` 코드를 "초등 1학년" 등으로 매핑하는 드롭다운 구현.
    *   **[v5.1] 학번 표시**: 상세 페이지에서 자동 생성된 학번(`20260001`)을 Read-Only로 표시.
    *   **퇴원 처리**: 상태(`재원`/`퇴원`) 변경 토글 및 퇴원일(`Datepicker`) 입력 UI.

### 📅 2주차: 핵심 비즈니스 로직 - 시간표 & 보강 (Core Logic)

**목표:** 복잡한 시간표 변경 정책과 보강 관리 UX를 구현합니다.

*   **Day 5: 시간표 변경 정책 모달**
    *   캘린더 일정 드래그/수정 시 팝업 구현:
        *   [이 일정만 변경] (Instance)
        *   [앞으로의 모든 일정 변경] (Series)
*   **Day 6: 수업 기록 및 출결 (LMS)**
    *   출결 상태 옵션 추가: `보강 필요(REQ_MAKEUP)` 선택 기능.
    *   일지 작성 모달 UI 개선.
*   **Day 7: 보강 잡기 UX (Makeup Class)**
    *   일정 등록 모달에 `수업 유형` 탭 추가 (정규수업 / 보강).
    *   **보강** 선택 시: `보강 필요` 상태인 학생 리스트 조회 및 선택(Mapping) UI 구현.

### 📅 3주차: 정산 및 데이터 시각화 (Settlement & Dashboard)

**목표:** 정확한 돈 계산(세금 포함)과 시각적인 대시보드를 구현합니다.

*   **Day 8: 정산 대시보드 UI**
    *   카드 UI 구현: `세전 총액`, `공제액(3.3%)`, `실지급액` 표시.
    *   "예상 실수령액" 문구 강조.
*   **Day 9: 정산 상세 내역 (Table)**
    *   월별 수업 횟수, 보강 횟수, 공제 내역 테이블 구현.
    *   엑셀 다운로드 버튼 연동.
*   **Day 10: 교재 관리 (Hybrid)**
    *   교재 검색 모달 (외부 API 연동 가정 UI).
    *   학원 전용 교재 등록 폼.

### 📅 4주차: 안정화 및 배포 (Stabilization)

**목표:** 전체 기능을 테스트하고 버그를 수정하여 배포 가능한 상태로 만듭니다.

*   **Day 11: 통합 테스트 (E2E)**
    *   시나리오 테스트: 가입 -> 승인 -> 강의 개설 -> 학생 등록 -> 출석 -> 정산.
*   **Day 12: UI/UX 폴리싱**
    *   모바일 반응형 레이아웃 점검.
    *   로딩 스피너, 에러 메시지 등 사용자 피드백 강화.
*   **Day 13: 배포 준비**
    *   환경 변수 분리 (`.env`).
    *   빌드 최적화.
