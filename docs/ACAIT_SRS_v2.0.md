# ACAIT Software Requirements Specification (SRS) v2.0

**프로젝트명**: ACAIT (Academy All-in-One IT Solution)  
**버전**: 2.0  
**작성일**: 2026-02-11  
**상태**: 구현 완료 (배포 준비 단계)

---

## 1. 개요 (Introduction)

### 1.1 목적
본 문서는 학원 관리 시스템 **ACAIT**의 기능 및 비기능 요구사항을 정의한다. v1.0의 기본 기능(일정, 학생 관리)에 더해, v2.0에서는 **정산 고도화, 수강료 이월 관리, 중간 관리자(실장) 역할, 학원 홍보 랜딩 페이지** 등 심화 기능이 통합된 현재 시스템의 형상을 명세한다.

### 1.2 범위
ACAIT는 소규모 공부방부터 중소형 학원까지 아우르는 SaaS 기반 학원 관리 솔루션이다.
*   **핵심 가치**: 복잡한 정산의 자동화, 유연한 출결 관리, 투명한 수강료 관리.
*   **주요 기능**: 구글 로그인, 캘린더 기반 일정 관리, 학생/학부모 관리, 강사료 정산(공제 항목 설정), 수강료 이월/차감 관리.

## 2. 사용자 역할 및 권한 (User Roles & Permissions)

시스템은 다음 4가지 역할을 정의하며, 각 역할별 권한은 다음과 같다.

| 역할 (Role) | 명칭 | 정의 및 주요 권한 |
| :--- | :--- | :--- |
| **ROLE_OWNER** | **원장** | **학원 최고 관리자**<br>- 학원 생성 및 설정 (초대 코드 관리, 공제 항목 설정)<br>- 강사 승인/거절 및 역할 변경 (강사↔실장)<br>- 모든 강사의 일정 조회 및 수정<br>- 전체 매출 및 강사료 정산 관리<br>- 모든 학생 및 수납 데이터 관리 |
| **ROLE_MANAGER** | **실장** | **중간 관리자 (v2.0 신규)**<br>- 원장에 준하는 운영 권한 보유 (정산/설정 제외)<br>- 학생 등록/수정/퇴원 처리<br>- 수강료 납부 처리 및 잔액 조회<br>- 모든 강사의 일정 조회 및 강의 개설(강사 지정 가능)<br>- *제한: 학원 설정(공제 항목), 강사 승인, 원장 권한 박탈 불가* |
| **ROLE_INSTRUCTOR** | **강사** | **일반 사용자**<br>- 본인의 강의 및 일정 관리<br>- 본인 수강생의 출결 및 수업 일지 기록<br>- 본인의 예상 정산 금액 조회<br>- *제한: 타 강사 일정/학생 조회 불가, 수납 처리 불가* |
| **ROLE_GUEST** | **게스트** | **가입 대기자**<br>- 구글 로그인 후 학원 가입 신청(초대 코드 입력) 상태<br>- 원장 승인 전까지 기능 접근 불가 |

## 3. 시스템 아키텍처 및 기술 스택

*   **Frontend**: React (Vite), TypeScript, Tailwind CSS, FullCalendar, React Query, Zustand.
*   **Backend**: Spring Boot 3.2, Java 17, JPA (Hibernate), Spring Security (OAuth2 + JWT).
*   **Database**: MySQL 8.0 (H2 for Test).
*   **Infrastructure**: Docker (예정).

## 4. 상세 기능 명세 (Functional Requirements)

### 4.1 인증 및 회원 관리 (Auth & Member)
1.  **소셜 로그인**: Google OAuth2를 통한 단일 인증 체계.
2.  **회원가입 프로세스**:
    *   최초 로그인 시 '원장(학원 생성)' 또는 '강사(초대 코드로 가입 신청)' 선택.
    *   강사는 가입 신청 후 `PENDING` 상태가 되며, 원장의 승인 후 `ACTIVE` 상태로 전환.
3.  **학원 정보 관리**:
    *   원장은 '학원 설정' 페이지에서 학원명, **초대 코드**, 최대 인원 수를 확인.
    *   초대 코드를 복사하여 강사에게 공유 가능.
4.  **강사 관리 (원장 전용)**:
    *   가입 신청한 강사 목록 조회 및 승인/거절.
    *   **역할 변경**: 승인된 강사의 역할을 드롭다운을 통해 '강사' ↔ '실장'으로 즉시 변경 가능.

### 4.2 강의 및 일정 관리 (Lecture & Schedule)
1.  **강의 개설**:
    *   유형: **판서 수업**(고정 시간표) vs **개별 진도**(유동 시간표).
    *   **강사 지정 (v2.0)**: 원장/실장은 강의 개설 시 담당 강사를 본인 또는 타 강사로 지정 가능.
    *   기본 수강료, 수업 시간, 요일별 정규 시간표 설정.
2.  **캘린더 뷰 (Dashboard)**:
    *   월/주/일 단위 일정 조회.
    *   **필터링 (v2.0)**: 원장/실장은 '전체 보기', '내 일정 보기', '특정 강사 보기' 필터 제공.
3.  **일정 수정 (Drag & Drop)**:
    *   일정을 드래그하여 날짜/시간 변경.
    *   반복 일정의 경우 '이번 일정만 변경' 또는 '이후 모든 일정 변경' 선택 가능.
4.  **휴강 및 보강**:
    *   특정 일정 삭제 시 휴강 처리.
    *   별도 보강 일정 등록 가능 (원래 수업과 연결).

### 4.3 학생 및 수강 관리 (Student & Enrollment)
1.  **학생 등록**: 이름, 학교, 학년, 학부모 연락처, 생년월일(인증용) 등 정보 관리.
2.  **수강 신청**:
    *   학생을 특정 강의에 등록.
    *   '개별 진도' 강의의 경우 학생별 맞춤 시간표 관리 가능.
3.  **상태 관리**: 재원/퇴원 상태 관리. 퇴원 시 퇴원일 기록.
4.  **권한**: 원장, 실장, 담당 강사만 학생 정보에 접근 가능. (실장은 전체 학생 관리 가능)

### 4.4 출결 및 수업 기록 (Attendance & Record)
1.  **수업 기록 생성**:
    *   캘린더의 일정을 클릭하여 출결 상태 및 수업 내용 기록.
    *   **출결 상태 세분화 (v2.0)**:
        *   `출석 (ATTENDED)`: 정상 수업 (차감 O, 정산 O).
        *   `지각 (LATE)`: 정상 수업 (차감 O, 정산 O).
        *   `당일 통보 결석 (ABSENT)`: 학생 귀책 결석 (차감 O, 정산 O).
        *   `사전 협의 결석 (REQ_MAKEUP)`: 보강 필요 (차감 X, 정산 X).
        *   `보강 수업 (MAKEUP)`: 사전 결석에 대한 보강 (차감 O, 정산 O).
        *   `휴강 (CANCELLED)`: 수업 취소 (차감 X, 정산 X).
2.  **수업 일지**: 진도 내용, 특이사항 텍스트 기록.
3.  **자동 연동**: 수업 기록 저장 시 **학생 잔액 차감** 및 **학습 이력**이 자동 생성됨.

### 4.5 수강료 및 이월 관리 (Tuition & Balance) - v2.0 New
1.  **수납 기록 (`TuitionPayment`)**:
    *   학생별 수강료 납부 내역 등록 (금액, 납부일, 대상 월).
2.  **잔액 관리 (`StudentBalance`)**:
    *   월별 잔액 자동 계산 로직:
        $$ \text{현재 잔액} = \text{전월 이월금} + \text{당월 납부액} - \text{당월 사용액(수업료)} $$
    *   수업 기록(`LectureRecord`) 생성 시 해당 강의의 단가만큼 `당월 사용액`이 실시간 증가하고 `현재 잔액`이 감소.
3.  **UI 제공**:
    *   학생 상세 페이지 내 **[수납/이월 내역]** 탭 제공.
    *   월별 납부액, 수업 사용액, 잔액 현황을 카드 형태로 시각화.

### 4.6 정산 관리 (Settlement) - v2.0 Enhanced
1.  **정산 기준**:
    *   강사료는 **수업 횟수 기반**으로 계산 (학생의 납부 여부와 무관하게 수업 진행 시 지급).
    *   정산 대상: `출석`, `지각`, `당일 통보 결석`, `보강 수업`.
2.  **공제 항목 설정 (`DeductionItem`)**:
    *   원장은 학원별 공제 항목을 동적으로 설정 가능.
    *   유형: `비율(%)` (예: 소득세 3.3%), `고정 금액(원)` (예: 식대, 비품비).
3.  **정산 산출**:
    *   $$ \text{총 강사료} = \sum (\text{수업 횟수} \times \text{강의 단가}) $$
    *   $$ \text{실 지급액} = \text{총 강사료} - \sum \text{공제 항목} $$
4.  **기능**:
    *   월별 정산 대시보드 (확정 금액, 공제액, 실지급액).
    *   예상 정산 금액 조회 (실시간 시뮬레이션).
    *   엑셀 다운로드 기능.

### 4.7 랜딩 페이지 (Landing Page) - v2.0 New
1.  **접근성**: 로그인 전 사용자 및 로고 클릭 시 접근.
2.  **구성**:
    *   Hero Section: 서비스 슬로건 및 시작하기/로그인 버튼.
    *   Feature Section: 주요 기능(일정, 정산, 학생 관리) 소개.
3.  **라우팅**: `/` (랜딩), `/schedule` (업무용 캘린더)로 분리.

## 5. 데이터 모델 (ERD 요약)

*   **Academy**: 학원 정보 (이름, 초대 코드, 최대 인원).
*   **Member**: 사용자 (Google Email, Role, Academy FK).
*   **Lecture**: 강의 정보 (이름, 유형, 단가, 강사 FK).
*   **Schedule**: 강의 정규 시간표.
*   **Student**: 학생 정보 (이름, 연락처, 상태).
*   **LectureStudent**: 수강생 매핑 (N:M).
*   **LectureRecord**: 수업 기록 (날짜, 출결 상태, 실제 시간).
*   **TuitionPayment (New)**: 수강료 납부 기록.
*   **StudentBalance (New)**: 월별 학생 잔액/이월금 스냅샷.
*   **Settlement**: 월별 강사 정산 기록.
*   **DeductionItem (New)**: 학원별 정산 공제 항목 설정.

## 6. 비기능 요구사항

1.  **보안**:
    *   모든 API는 JWT 기반 인증/인가 수행.
    *   데이터 접근 시 `AcademyID` 기반의 멀티 테넌시 격리 필수.
    *   민감 정보(연락처 등)는 적절한 접근 제어 적용.
2.  **확장성**:
    *   `javax` -> `jakarta` 마이그레이션 완료 (Spring Boot 3.x 호환).
    *   향후 알림 서비스(KakaoTalk/SMS) 연동을 고려한 설계.
3.  **사용자 경험 (UX)**:
    *   반응형 웹 디자인 (모바일/태블릿 지원).
    *   직관적인 캘린더 인터페이스 및 모달 기반의 빠른 데이터 입력.
