# ACAIT 프론트엔드 개발 일정 및 로드맵 (v5.0 반영)

**작성일:** 2026-01-14
**기반 문서:** `요구사항명세서_v5.md`
**목표:** SaaS형 멀티 테넌시 아키텍처 및 고도화된 학원 관리 기능(보강, 퇴원, 세금) 구현

---

## 1. 현재 진행 상황 점검 (Status Check)

기존에 개발된 기능들은 **단일 학원(Single Tenant)** 구조를 가정하고 있어, v5.0 명세(멀티 테넌시)에 맞춘 **대대적인 리팩토링**이 필요합니다.

| 기능 | 현재 상태 | v5.0 대응 필요 사항 | 난이도 |
| :--- | :--- | :--- | :--- |
| **프로젝트 셋업** | ✅ 완료 | - | - |
| **인증 (로그인)** | ⚠️ 부분 완료 | `academy_id` 식별 로직 추가, 초대 코드 가입 플로우 구현 | High |
| **회원가입** | ⚠️ 부분 완료 | 학원 생성(Owner) vs 초대 가입(Instructor) 분기 처리 | High |
| **캘린더 뷰** | ✅ 완료 | 보강 일정(MAKEUP) 시각적 구분, 시간표 수정 모달(Instance/Series) | High |
| **수강생 관리** | ⚠️ 부분 완료 | 퇴원 상태(`DISCHARGED`) 및 퇴원일 관리 UI 추가 | Mid |
| **강의 관리** | ⚠️ 부분 완료 | - | Low |
| **정산 관리** | ❌ 미구현 | 세금(3.3%) 계산 로직 및 대시보드 UI 구현 | Mid |

---

## 2. 상세 개발 일정 (Roadmap)

### 📅 1주차: 멀티 테넌시 기반 재설계 (Foundation)

**목표:** 학원별 데이터 격리 구조를 프론트엔드에 적용하고, 새로운 가입 플로우를 완성합니다.

*   **Day 1: 인증 스토어 및 API 리팩토링**
    *   `authStore.ts`: `user` 객체에 `academyId`, `role`(`OWNER`/`INSTRUCTOR`) 추가.
    *   API Client: 모든 요청 헤더에 `X-Academy-Id` (또는 토큰 내 포함) 처리 확인.
*   **Day 2: 학원 생성 및 초대 가입 (New)**
    *   `/register` 페이지 분리:
        *   **학원장 가입**: 학원명 입력 -> 학원 생성 -> Owner 권한 부여.
        *   **강사 가입**: 초대 코드 입력 -> 해당 학원 소속으로 가입 신청.
*   **Day 3: 강사 승인 및 인원 제한**
    *   관리자 페이지: 강사 승인 시 `403 PLAN_LIMIT` 에러 핸들링 (고객센터 문의 모달).
*   **Day 4: 수강생 관리 고도화 (퇴원)**
    *   수강생 상세/수정 페이지: 상태(`재원`/`퇴원`) 변경 토글 및 퇴원일(`Datepicker`) 입력 UI.

### 📅 2주차: 핵심 비즈니스 로직 - 시간표 & 보강 (Core Logic)

**목표:** 복잡한 시간표 변경 정책과 보강 관리 UX를 구현합니다.

*   **Day 5: 시간표 변경 정책 모달**
    *   캘린더 일정 드래그/수정 시 팝업 구현:
        *   [이 일정만 변경] (Instance)
        *   [앞으로의 모든 일정 변경] (Series)
*   **Day 6: 수업 기록 및 출결 (LMS)**
    *   출결 상태 옵션 추가: `보강 필요(REQ_MAKEUP)` 선택 기능.
    *   일지 작성 모달 UI 개선.
*   **Day 7: 보강 잡기 UX (Makeup Class)**
    *   일정 등록 모달에 `수업 유형` 탭 추가 (정규수업 / 보강).
    *   **보강** 선택 시: `보강 필요` 상태인 학생 리스트 조회 및 선택(Mapping) UI 구현.

### 📅 3주차: 정산 및 데이터 시각화 (Settlement & Dashboard)

**목표:** 정확한 돈 계산(세금 포함)과 시각적인 대시보드를 구현합니다.

*   **Day 8: 정산 대시보드 UI**
    *   카드 UI 구현: `세전 총액`, `공제액(3.3%)`, `실지급액` 표시.
    *   "예상 실수령액" 문구 강조.
*   **Day 9: 정산 상세 내역 (Table)**
    *   월별 수업 횟수, 보강 횟수, 공제 내역 테이블 구현.
    *   엑셀 다운로드 버튼 연동.
*   **Day 10: 교재 관리 (Hybrid)**
    *   교재 검색 모달 (외부 API 연동 가정 UI).
    *   학원 전용 교재 등록 폼.

### 📅 4주차: 안정화 및 배포 (Stabilization)

**목표:** 전체 기능을 테스트하고 버그를 수정하여 배포 가능한 상태로 만듭니다.

*   **Day 11: 통합 테스트 (E2E)**
    *   시나리오 테스트: 가입 -> 승인 -> 강의 개설 -> 학생 등록 -> 출석 -> 정산.
*   **Day 12: UI/UX 폴리싱**
    *   모바일 반응형 레이아웃 점검.
    *   로딩 스피너, 에러 메시지 등 사용자 피드백 강화.
*   **Day 13: 배포 준비**
    *   환경 변수 분리 (`.env`).
    *   빌드 최적화.
