# ACAIT 고도화 작업 히스토리

## 2026-02-01 (1단계: 기반 마련 완료)

### 1. 출결 상태 개선 (Attendance Status Improvement)
*   **목표**: 결석 유형 세분화 및 휴강 개념 도입.
*   **Backend**:
    *   `AttendanceStatus` Enum에 `CANCELLED` (휴강) 추가.
    *   `SettlementService`에서 `CANCELLED` 상태는 정산 대상에서 자동 제외됨을 확인.
*   **Frontend**:
    *   `LectureRecordModal.tsx` UI 수정.
        *   출결 옵션에 `휴강` 추가.
        *   `결석` -> `당일 통보 결석`, `보강 필요` -> `사전 협의 결석`으로 텍스트 변경.

### 2. 역할 배정 기능 (Role Assignment Feature)
*   **목표**: 원장이 강사의 역할을 '강사' 또는 '실장'으로 변경할 수 있도록 함.
*   **Backend**:
    *   `Role` Enum에 `ROLE_MANAGER` (실장) 추가.
    *   `Member` 엔티티에 `updateRole` 메서드 추가.
    *   `MemberRoleUpdateRequest` DTO 생성.
    *   `AdminService` 인터페이스 및 구현체(`AdminServiceImpl`) 생성 (역할 변경 로직 포함).
    *   `AdminController`에 역할 변경 API (`PUT /api/v1/admin/members/{memberId}/role`) 추가.
    *   기존 `AdminController`의 API 경로를 `/api/v1/admin` 하위로 변경 및 리팩토링.
*   **Frontend**:
    *   `api/adminApi.ts`에 `updateMemberRole` 함수 추가 및 API 경로 수정.
    *   `InstructorPage.tsx` (강사 관리 페이지) UI 개선.
        *   강사 목록에 '역할' 컬럼 추가.
        *   역할 뱃지 클릭 시 '강사' <-> '실장' 변경 기능 구현.
